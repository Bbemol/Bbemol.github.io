# Champagne Lejeune

Site vitrine de Champagne Lejeune Père & Fils, propriétaires-récoltants à Villers-Marmery depuis 1684.

**Voir le site : https://&lt;utilisateur&gt;.github.io/champagne-lejeune/**

## Lancer en local

Site statique, sans installation ni build :

```sh
python3 -m http.server 8000
```

puis ouvrir http://localhost:8000.

## Contenu

- `index.html` — pages et balisage
- `css/styles.css` — styles
- `js/app.js` — données des cuvées et navigation
- `assets/` — photos
